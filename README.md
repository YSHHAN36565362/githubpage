## 사진을 추가하는 법

```sh
# 1. 원본을 여행 폴더에 넣습니다 (베스트 컷만, 여행당 10~20장)
open photo/photos/2025-08_europe/

# 2. 웹용 사본과 데이터를 생성합니다
cd photo && python3 build.py

# 3. thumbs/ 와 data/ 만 커밋하면 됩니다 (원본은 .gitignore 로 제외됨)
```

### 왜 원본을 올리지 않는가

정리된 하루치 폴더가 25장에 300MB 수준이라, 원본을 그대로 커밋하면
GitHub Pages 권장 용량(1GB)을 여행 서너 건 만에 넘깁니다.

`build.py` 는 원본을 **건드리지 않고** `thumbs/` 에 웹용 사본 두 장만 만듭니다.

| 생성물 | 크기 | 쓰이는 곳 |
|---|---|---|
| `*_600.jpg`  | 장당 약 40–80KB   | 갤러리 타일 · 지구본 마커 · 이력서 미리보기 |
| `*_1600.jpg` | 장당 약 200–400KB | 라이트박스 확대 |

여행 9건 × 15장 ≈ 135장 ≈ **40MB**. 웹에서 보는 용도로 1600px 이면 충분하고,
그 이상은 화면에서 차이가 나지 않으면서 로딩만 느려집니다.

## 고치기 전에 읽을 것

- `DESIGN.md` — 이력서 페이지. **7절 「절대 규칙」은 두 페이지 공통**입니다.
- `photo/DESIGN.md` — 사진 페이지(지구본 · 도구 알고리즘 · 다크 테마).

핵심만 옮기면:

1. **ES 모듈 / import map / 외부 JS CDN 금지.** 2026-08-13 에 CDN 로드 실패로
   배포된 사이트가 통째로 망가진 적이 있습니다.
2. 라이브러리는 저장소에 동봉하고, **없어도 페이지는 동작**해야 합니다.
3. 숨김의 기본값은 "보임". JS 가 죽어도 본문이 읽혀야 합니다.
4. CSS / JS 를 고칠 때마다 `?v=` 캐시 무효화 숫자를 올리세요.
